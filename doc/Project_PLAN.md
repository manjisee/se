## 1. 프로젝트 개요

### 1.1 문서의 목적
본 문서는 ShareBox 프로젝트를 수행하기 위한 프로젝트 관리 계획서이다. 프로젝트의 목표, 개발 일정, 팀 구성, 품질 관리, 위험 관리, 산출물 관리 방법을 정리하는 것을 목적으로 한다.

### 1.2 프로젝트 소개
ShareBox는 소규모 팀이 파일을 업로드하고 공유할 수 있는 웹 기반 파일 공유 시스템이다. 사용자는 파일을 업로드하고, 필요한 파일을 검색하거나 다운로드할 수 있다. 또한 파일 변경 이력을 확인하여 팀원 간 파일 버전 혼동을 줄일 수 있다.

### 1.3 프로젝트 목표
본 프로젝트의 목표는 팀 단위 파일 공유를 더 편리하고 안전하게 만드는 것이다.

주요 목표는 다음과 같다.

1. 파일 업로드 및 다운로드 기능 구현
2. 파일 검색 기능 구현
3. 파일 변경 이력 관리 기능 구현
4. 팀원별 접근 권한 관리 기능 구현
5. GitHub를 이용한 문서 및 산출물 관리

## 2. 개발 계획

### 2.1 개발 방법
본 프로젝트는 Agile Scrum 방식을 사용한다. 기능을 한 번에 모두 완성하기보다, 파일 업로드, 다운로드, 검색, 권한 관리 기능을 단계별로 구현하고 테스트한다.

### 2.2 주요 기능

| 기능 | 설명 |
|---|---|
| 파일 업로드 | 사용자가 파일을 시스템에 업로드한다. |
| 파일 다운로드 | 사용자가 저장된 파일을 다운로드한다. |
| 파일 검색 | 파일명이나 태그로 원하는 파일을 찾는다. |
| 권한 관리 | 파일별로 접근 가능한 사용자를 설정한다. |
| 변경 이력 관리 | 파일 수정자, 수정 날짜, 변경 내용을 기록한다. |
