# 1. 서론

## 1.1 문서 목적 및 범위

본 문서는 소프트웨어공학 프로젝트로 설계한 WorkDrive의 주요 기능을 테스트하기 위해 작성한 테스트 보고서이다.

WorkDrive는 사용자가 파일을 업로드하고, 저장된 파일을 조회하거나 다운로드할 수 있으며, 공유 링크를 이용해 다른 사용자와 파일을 공유할 수 있는 클라우드 파일 관리 시스템이다.

본 문서에서는 WorkDrive의 사용자 인증, 파일 업로드, 파일 조회, 파일 검색, 파일 다운로드, 파일 공유, 파일 삭제 기능에 대한 테스트 케이스를 작성한다. 또한 시스템 응답 속도와 사용자 접근 권한에 대한 비기능 테스트도 함께 설계한다.

현재 WorkDrive는 설계 단계이며 실제 시스템이 구현되지 않았다. 따라서 본 보고서에서는 실제 테스트를 수행하지 않고 테스트 조건, 입력값, 수행 절차와 예상 결과를 작성한다. 실제 구현이 완료된 이후에는 각 테스트 케이스의 실제 결과를 기록하고 PASS 또는 FAIL 여부를 판단할 예정이다.

## 1.2 프로젝트 개요

WorkDrive는 웹 환경에서 파일을 저장하고 관리할 수 있도록 제공되는 클라우드 파일 공유 시스템이다.

사용자는 로그인한 후 파일을 업로드하고, 업로드된 파일의 목록을 확인할 수 있다. 필요한 파일을 검색하거나 다운로드할 수 있으며, 공유 링크를 생성하여 다른 사용자에게 파일을 전달할 수 있다. 사용하지 않는 파일은 삭제할 수 있다.

또한 로그인하지 않은 사용자나 접근 권한이 없는 사용자가 개인 파일에 접근하지 못하도록 사용자 인증과 접근 권한을 확인한다.

## 1.3 용어 정의

| 용어 | 설명 |
|:---|:---|
| 사용자 인증 | 이메일과 비밀번호를 이용하여 사용자의 신원을 확인하는 과정 |
| 파일 업로드 | 사용자의 컴퓨터에 있는 파일을 WorkDrive 서버에 저장하는 기능 |
| 파일 다운로드 | WorkDrive 서버에 저장된 파일을 사용자의 컴퓨터로 받는 기능 |
| 파일 목록 | 사용자가 업로드한 파일의 이름, 크기, 업로드 날짜 등을 보여주는 화면 |
| 공유 링크 | 다른 사용자가 특정 파일에 접근할 수 있도록 생성되는 주소 |
| 접근 권한 | 사용자가 특정 파일을 조회하거나 다운로드할 수 있는 권한 |
| 블랙박스 테스트 | 프로그램의 내부 코드를 확인하지 않고 입력값과 실행 결과를 통해 기능을 검사하는 테스트 |
| PASS | 실제 결과가 예상 결과와 일치한 상태 |
| FAIL | 실제 결과가 예상 결과와 일치하지 않은 상태 |
| N/T | 시스템이 구현되지 않아 테스트를 수행하지 않은 상태 |

# 2. 테스트 개요

## 2.1 테스트 방법

WorkDrive 테스트는 사용자의 입장에서 기능을 실행하고 결과를 확인하는 블랙박스 테스트 방식으로 설계한다.

시스템의 내부 코드나 데이터 처리 과정을 직접 확인하기보다는 사용자가 입력한 값에 따라 올바른 결과가 출력되는지를 검사한다.

정상적인 입력뿐만 아니라 잘못된 입력, 권한이 없는 접근, 존재하지 않는 파일 요청과 같은 예외 상황도 함께 테스트한다.

## 2.2 테스트 범위

| 테스트 범위 | 테스트 내용 |
|:---|:---|
| 사용자 인증 | 올바른 로그인 정보와 잘못된 로그인 정보 처리 확인 |
| 파일 업로드 | 정상 파일 업로드와 허용 용량 초과 파일 처리 확인 |
| 파일 조회 | 업로드한 파일이 파일 목록에 정확히 표시되는지 확인 |
| 파일 검색 | 파일 이름을 이용한 검색 결과 확인 |
| 파일 다운로드 | 저장된 파일의 다운로드와 존재하지 않는 파일 요청 처리 확인 |
| 파일 공유 | 공유 링크 생성 및 공유 링크 접근 확인 |
| 파일 삭제 | 파일 삭제와 삭제 취소 기능 확인 |
| 성능 | 주요 기능의 응답 시간이 설정된 기준을 만족하는지 확인 |
| 보안 | 비로그인 사용자와 권한이 없는 사용자의 접근 차단 확인 |

## 2.3 테스트 항목 및 통과 기준

### 기능 테스트 통과 기준

| 기능 | 통과 기준 |
|:---|:---|
| 로그인 | 가입된 사용자가 올바른 이메일과 비밀번호를 입력한 경우에만 로그인에 성공한다. |
| 파일 업로드 | 허용된 파일은 서버에 정상적으로 저장되고 파일 목록에 표시된다. |
| 파일 조회 | 로그인한 사용자의 파일 정보가 빠짐없이 목록에 표시된다. |
| 파일 검색 | 입력한 검색어가 포함된 파일만 검색 결과에 표시된다. |
| 파일 다운로드 | 사용자가 선택한 파일이 손상되지 않은 상태로 다운로드된다. |
| 파일 공유 | 공유 링크가 정상적으로 생성되고 허용된 사용자가 파일에 접근할 수 있다. |
| 파일 삭제 | 삭제한 파일이 파일 목록에서 제거되고 다시 접근할 수 없다. |

### 비기능 테스트 통과 기준

| 테스트 항목 | 통과 기준 |
|:---|:---|
| 일반 응답 속도 | 로그인, 파일 목록 조회, 검색 등의 주요 요청이 일반적인 환경에서 2초 이내에 처리된다. |
| 최초 응답 시간 | 최초 화면 또는 최초 요청에 대한 응답이 3초 이내에 표시된다. |
| 사용자 인증 | 로그인하지 않은 사용자는 파일 관리 화면을 사용할 수 없다. |
| 접근 권한 | 사용자는 다른 사용자의 비공개 파일에 접근할 수 없다. |
| 브라우저 호환성 | Chrome과 Edge에서 주요 기능이 동일하게 동작한다. |

# 3. 테스트 케이스

## 3.1 테스트 케이스 선정 기준

테스트 케이스는 WorkDrive 요구사항의 주요 기능을 기준으로 선정하였다.

각 기능에 대해 정상적으로 처리되어야 하는 상황과 오류가 발생할 수 있는 상황을 구분하여 테스트 케이스를 작성하였다.

테스트 케이스에는 다음 내용을 포함한다.

- 테스트 대상 기능
- 테스트를 시작하기 전에 필요한 조건
- 사용자가 입력하는 값 또는 수행하는 행동
- 예상되는 실행 결과
- 실제 테스트 결과
- 최종 판정

현재는 실제 구현 전이므로 실제 결과와 판정은 모두 N/T로 표시한다.
